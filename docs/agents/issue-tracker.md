# Issue Tracker

Issue tracker: GitHub Issues for `iwindd/ugh-cloud`.

Use GitHub Issues for approved, actionable implementation work. Each issue must have a clear outcome, acceptance criteria, scope boundaries, and explicit blockers when applicable.

Create issues only after the user approves the ticket breakdown. Create one issue per independently verifiable tracer-bullet slice. Link implementation pull requests back to the issue.

Verify every created issue with `gh issue view <number> --repo iwindd/ugh-cloud` before reporting success. Do not include credentials or secret values in issue bodies.
