# Domain Documentation

Layout: single-context.

- `CONTEXT.md` is the working domain context, vocabulary, accepted decisions, and unresolved questions.
- `docs/adr/` is for durable decisions that are difficult to reverse.
- `ARCHITECTURE.md` is the stable code structure and dependency-direction reference.
- `AGENTS.md` is the compact repository router and rule set.

Read `CONTEXT.md` when shaping a feature or implementing an issue that changes domain behavior. Read `ARCHITECTURE.md` when changing module boundaries or dependencies. Keep task execution in GitHub Issues rather than adding a root planning document.
